Java Opdracht - Wakken, IJsberen en Pinguïns

Voor de eindopdracht van Java heb ik in Apache Netbeans een dobbelsteenspel gemaakt. Het programma is opgesplitst in vijf klassen. De klasse Dobbelsteen vormt de kern van het spel en berekent via een array het aantal wakken, ijsberen en pinguïns. De klasse Spel beheert een ArrayList van dobbelstenen en controleert antwoorden. De score wordt bijgehouden in een aparte Score klasse. De grafische interface is gebouwd met Java Swing. DobbelsteenPanel tekent de dobbelstenen via Graphics2D, waarbij de middelste stip blauw oplicht als wak. MainFrame bouwt het volledige venster op met invoervelden, knoppen en een scorebord. Tot slot zijn er JUnit 5 testklassen geschreven voor alle logische klassen.
